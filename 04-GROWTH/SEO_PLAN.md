# SEO

Each page should target one search query.

Example:
- EMI Calculator
- PNG to WebP
- ChatGPT vs Claude

Checklist:
- Title
- Meta description
- Structured headings
- Sitemap
- Robots
- Internal links
- Original content before monetization
- Clear disclosure on affiliate pages

URL strategy:
- Use one main domain
- Put each tool under a clean route
- Build topical authority around Kyzentria

Examples:
- kyzentria.com/calculator/emi
- kyzentria.com/image/png-to-webp
- kyzentria.com/compare/chatgpt-vs-claude
