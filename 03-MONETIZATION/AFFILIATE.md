# Affiliate Strategy

Affiliate links should appear only where they genuinely help the user choose a tool, product, or service.

Best Kyzentria pages for affiliate income:
- /hosting
- /compare
- /developer
- /seo
- /prompt
- /resume
- /image
- /pdf

Good affiliate categories:
- Web hosting
- Domain registrars
- AI tools
- PDF software
- Image tools
- Resume builders
- SEO tools
- Developer tools
- Design tools
- Productivity software

Recommended programs to research:
- Amazon Associates
- Namecheap
- Hostinger
- DigitalOcean
- Canva
- Semrush
- Grammarly
- Notion
- Adobe
- Envato

Rules:
- Add affiliate links only after the page has useful original content.
- Do not hide affiliate links inside fake recommendations.
- Add a short affiliate disclosure near affiliate links.
- Compare tools honestly, including pros and cons.
- Prefer evergreen products with clear user intent.
- Track clicks with analytics events.

Simple disclosure:

Some links on this page may be affiliate links. If you buy through them, Kyzentria may earn a commission at no extra cost to you.

Best early approach:

1. Build useful free tools first.
2. Add comparison sections below the tool.
3. Add affiliate links where the recommendation is natural.
4. Test which pages get traffic before adding too many offers.
5. Keep the page useful even if all affiliate links are removed.
