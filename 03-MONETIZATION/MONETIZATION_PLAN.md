# Monetization Plan

Kyzentria can earn money through four main channels:

1. Affiliate links
2. Display ads
3. Sponsored placements
4. Digital products or paid upgrades later

## Phase 1: Build Trust

Focus on free tools and helpful content.

Needed before applying to ad or affiliate networks:
- Public website
- Original content
- Clear navigation
- Privacy policy
- Contact page
- Sitemap
- Mobile-friendly layout
- No broken pages

## Phase 2: Add Affiliate Links

Start with pages that naturally connect to buying decisions.

Best first routes:
- /hosting
- /compare
- /seo
- /developer
- /resume

Examples:
- /hosting/best-cheap-hosting
- /compare/canva-vs-adobe-express
- /seo/best-rank-tracking-tools
- /developer/best-json-tools
- /resume/best-resume-builders

## Phase 3: Add Ads

Add ads only after traffic starts.

Best ad pages:
- Long guides
- Tool explainers
- Comparison pages
- Templates and examples

Avoid ads inside the main tool workflow.

## Phase 4: Add Sponsored Listings

After Kyzentria has traffic, sell simple sponsored placements.

Examples:
- Sponsored tool in a comparison table
- Sponsored hosting provider
- Sponsored resume builder
- Sponsored AI tool

Always label sponsored placements clearly.

## Phase 5: Add Paid Products

Later, add paid extras if users keep returning.

Ideas:
- Premium templates
- Download packs
- PDF export bundle
- Resume templates
- SEO checklist pack
- Prompt packs
- No-ads version

## Best First Money Pages

1. /hosting
2. /compare
3. /seo
4. /resume
5. /developer
6. /prompt
7. /pdf
8. /image

## Important Rule

Every money page must still be useful without the money link. That protects SEO, user trust, and long-term brand value.
